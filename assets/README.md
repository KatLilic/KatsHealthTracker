# Assets Folder

Place the following image files in this folder:

## Required Files

1. **icon.png** (1024x1024 pixels)
   - App icon for home screen
   - Must be a square PNG, no transparency

2. **splash.png** (1284x2778 pixels)
   - Splash screen shown when app launches
   - Should match your app's branding

3. **adaptive-icon.png** (1024x1024 pixels)
   - For Android adaptive icons
   - Square PNG with transparent background

## Quick Start

You can use free online tools to create these:
- https://www.canva.com (create designs)
- https://icon.kitchen (generate app icons)
- https://appicons.co (icon generator)

## Temporary Solution

If you want to run the app without custom icons, create simple placeholder images:

1. Create a 1024x1024 solid blue (#4A90D9) square → save as `icon.png`
2. Create a 1284x2778 solid blue (#4A90D9) rectangle → save as `splash.png`
3. Copy `icon.png` → save as `adaptive-icon.png`

Or just run the app - Expo will use default placeholders!
